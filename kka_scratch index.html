Suplemen Materi Modul 2

Algoritma & Konsep Sekuens (Sequence)

1. Konsep Sekuens (Sequence)

Sekuens adalah urutan eksekusi perintah langkah demi langkah dari atas ke bawah. Komputer selalu menjalankan instruksi sesuai dengan urutan baris blok yang disusun. Jika urutan blok tertukar, hasil aksi program akan salah secara logika.

2. Pemicu Program (Events)

Blok ketika bendera hijau diklik berfungsi sebagai pemicu utama (trigger). Tanpa adanya blok pemicu di posisi paling atas, rangkaian blok di bawahnya tidak akan dapat dijalankan oleh sistem.

Contoh Analisis Sekuens Percakapan & Gerakan

Urutan Logis (Benar)
  1. ketika bendera hijau diklik
  2. katakan "Hai!" selama 2 detik
  3. pindah 5 langkah
  4. tunggu 2 detik
  5. katakan "Aku siap!"

✔ Kucing menyapa dulu, lalu berjalan.

Urutan Keliru (Tidak Logis)
  1. ketika bendera hijau diklik
  2. pindah 5 langkah
  3. katakan "Hai!" selama 2 detik
  4. tunggu 2 detik
  5. katakan "Aku siap!"

✖ Kucing berjalan dulu baru menyapa.

Suplemen Materi Modul 3

Konsep Debugging & Perbaikan Logika Error

1. Apa itu Debugging?

Proses sistematis mendeteksi, mengidentifikasi, dan memperbaiki kesalahan (bug) pada susunan logika blok agar program berjalan sesuai harapan.

2. Amati Gejala Bug

Jalankan program dan perhatikan titik di mana karakter bertindak tidak wajar (misal: membal balik, animasi terlalu cepat, atau diam saja).

3. Solusi Terstruktur

Tambahkan pemicu (Events), kontrol jeda waktu (wait), atau kontrol batas layar (if on edge bounce) secara tepat.
